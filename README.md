## Tech Stack
**Frontend**: React.js 18, Redux Toolkit, Tailwind CSS, Socket.io-client  
**Backend**: Node.js, Express.js, JWT, Socket.io  
**Database**: MongoDB Atlas  
**Payment**: Razorpay API  
**Deployment**: AWS EC2, Nginx

## Key Features
- Direct farmer to merchant trading - No middlemen
- Real-time price updates using Socket.io
- Instant UPI payments via Razorpay  
- Geo-location based "Near Me" product search
- Mobile OTP Authentication
- 20-30% Higher profit for farmers

## How to Run Locally
1. Clone: `git clone https://github.com/agritrade-hub-nidhi/agritradehub.git`
2. Backend: `cd backend && npm install && npm run dev`
3. Frontend: `cd frontend && npm install && npm start`
4. Add `.env` file in backend with MongoDB URI & Razorpay keys
